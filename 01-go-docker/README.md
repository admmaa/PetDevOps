Простое приложение на порту 8080 с приветствием "Hello DevOps!"

Необходим установленный docker. Если система Windows, так же необходим WSL и включенная виртуализация.

Для запуска скачайте проект из репозитория, перейдите в него и в термиле выполните команду "docker compose up -d --build"
Откройте браузер и вбейте 127.0.0.1:8080
